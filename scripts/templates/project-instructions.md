# 各AIのプロジェクト指示に入れる文

ChatGPT のプロジェクト指示、Claude のプロジェクト指示、Gemini の Gem の指示に、次の文をそのまま入れます。Codex、Claude Code、Gemini CLI のようにリポジトリの中で動くツールは、AGENTS.md などを自動で読むため不要です。

```text
このプロジェクトの作業記録は GitHub リポジトリ {{REPO}} に、成果物は Google Drive の {{DRIVE}}/ に保存する。

会話の最初に【記録不要】とあれば、記録も確認もせず、ここから下の指示は使わない。

会話の最初の返信の前に、GitHub の接続でこのリポジトリの AGENTS.md と docs/record-format.md を開いて読む。最初の返信の冒頭に「AGENTS.md（記録形式 第◯版）を読みました」と、読んだ版を書く。読めなかった場合は何も保存せず、読めなかったことと原因を伝えて止まる。

記録（要約エントリと原文）は GitHub の themes/ に保存する。Drive に置くのは、成果物（Word、PDF、スライド、表、画像、データ）と会話の全文・長いログだけにする。

IDの形式、ファイル名、保存の手順は AGENTS.md に書かれたとおりにし、別の形式を作らない。

会話の最初に【記録先】があれば、そのテーマとセッションに記録する。【記録先】がなければ、最初の返信で記録先のテーマを確認する。
```

指示の文を変えたときは、各AIのプロジェクト指示に入れ直します。

## 会話の最初に書く1行

```text
【記録先】{{REPO_NAME}} ／ テーマ：<テーマID> ／ セッション：新規
```

新しいテーマを始めるときは、テーマを `新規 <英数字の名前>「<題名>」` にします。進行中のテーマIDは [STATUS.md](../STATUS.md) で確認できます。
